# 项目待处理问题清单

> 创建：2026-08-04 ｜ 来源：全项目体检
>
> 优先级：P0 紧急（安全/数据风险）> P1 重要（功能缺陷/体验）> P2 优化（锦上添花）
>
> **更新：2026-08-04 全部修复完成**，详情见「修复记录」。

## 高优先级（P0）

### 1. 免费 AI 体验可被刷

- **问题**：`deviceId` 由客户端生成并自报，后端只按 deviceId 判断免费次数，攻击者修改 deviceId 即可无限次免费 AI 优化。
- **位置**：`card-backend/server.js`（`handleApi` 中 `isTrial` 判断）、前端传入 `deviceId`
- **建议**：服务端叠加 IP + User-Agent 维度限制；或改为验证码/登录门槛。

### 2. 管理台与兑换接口无限流

- **问题**：`/api/card-admin/*` 和 `/api/redeem-card` 无频率限制，9090 端口直接暴露公网，存在暴力尝试管理员密钥、批量试卡密风险。
- **位置**：`card-backend/server.js`
- **建议**：加 IP 级限流（如每分钟 N 次）；管理台建议仅内网访问或加 IP 白名单。

### 3. 生产环境缺进程守护与 HTTPS

- **问题**：无 pm2/systemd/NSSM 配置，服务器重启后服务不会自动拉起；部署为裸 HTTP，`COOKIE_SECURE` 无法启用。
- **位置**：部署层
- **建议**：Nginx 反代 + HTTPS 证书 + 进程守护（pm2 或 NSSM）；提供部署脚本。

## 中优先级（P1）

### 4. CSV 公式注入

- **问题**：CSV 导出直接 `join(",")`，未对以 `= + - @` 开头的字段加 `'` 前缀，Excel 打开时可能被当作公式执行。
- **位置**：Web `script.js`（`exportCsv`）、小程序 `pages/index/index.js`（`renderExportCanvas` / CSV 相关）
- **建议**：导出前对危险前缀字段加单引号转义。

### 5. 小程序下载体积风险

- **问题**：`wx.request` 直接传 canvas 转出的 base64（上限约 10MB），220 格大图纸可能超限，真机静默失败。
- **位置**：`D:\pixelbeans-wechat\pages\index\index.js`（`submitDownload`）
- **建议**：后端保存临时文件 + 小程序 `wx.downloadFile` 下载；或分块上传。

### 6. 静态资源无缓存头

- **问题**：`script.js`（约 91KB）、`palettes.js`（约 69KB）响应无 Cache-Control / ETag，每次刷新全量下载。
- **位置**：`server.js`（前端静态服务）
- **建议**：加 Cache-Control（带 hash 的文件长缓存，入口文件协商缓存）。

## 低优先级（P2）

### 7. 缺少安全响应头

- **问题**：`X-Content-Type-Options`、`Referrer-Policy` 等安全头未设置（页面无外部资源，影响小）。
- **建议**：静态服务统一加安全头。

### 8. 小程序端无打印/PDF 导出

- **问题**：Web 端有打印按钮，小程序端只有 PNG / CSV。
- **建议**：小程序增加图纸 PDF 生成或分享图片。

### 9. cards.json 无备份机制

- **问题**：卡密、次数、日志唯一数据源无自动备份，硬盘故障或误删即丢失。
- **建议**：每日自动备份到 `backup/` 目录，保留 N 天。

### 10. 测试脚本无统一入口

- **问题**：`tools/` 下有 Playwright 测试，但无 `npm test` 统一入口；小程序 `index.js` 有残留空函数 `noop()`。
- **建议**：补充 package.json scripts，清理遗留代码。
