# 拼豆图纸生成器 · 功能清单

> 最后更新：2026-08-06

项目包含四个部分：

| 部分 | 位置 | 说明 |
| --- | --- | --- |
| Web 端 | 项目根目录 `index.html` / `script.js` / `palettes.js` / `styles.css` | 主站，默认 8789 端口 |
| 小程序端 | `D:\pixelbeans-wechat` | 微信小程序，与 Web 端同风格 |
| 卡密后端 | `card-backend/` | API 服务，默认 9090 端口 |
| 管理后台 | `card-backend/卡密/index.html` | 卡密生成与查看，经 8789 或 9090 访问 |

---

## 一、Web 端（8789 端口）

### 1. 图片导入与生成

- 上传图片（JPG / PNG / WebP，≤12MB），支持点击选择和拖拽上传
- 创建空白画布（横向格数 10–220 可调）
- 本地像素化处理：图片缩放、颜色量化（合并级可调）、边缘连通白底识别（背景不计入用量）
- 实时生成拼豆图纸预览（自适应画布宽度）

### 2. AI 优化（需卡密 / 免费体验）

- AI 优化开关与提示词编辑、确认
- 优化中遮罩提示、结果缓存（同图同提示词不重复扣次）
- 优化中显示已等待时长（秒），支持取消本次优化
- 原图 vs 预处理结果对比面板（缩略图）
- 未输入卡密时可免费使用一次 AI 优化（按设备指纹）
- 卡密失效 / 次数用尽时弹出错误提示，再次点击弹卡密输入框

### 3. 色板系统

- 10 套色板：经典 24 色、柔和 18 色、高饱和 20 色，以及 Perler 103、Hama Midi 92、Artkal S 199 / C 174 / R 89、Nabbi 30、Yant 119（默认 Nabbi）
- 色板切换：有图时重新采样，手绘 / 空白图纸重映射到新色板并保留手绘内容
- 最近色匹配（加权欧氏距离）
- 色块悬停显示色号名称（如 N01 Black），统计清单同时显示色名
- 色板代表色预览（下拉框下方 8 个色点，切换即时更新）
- 色系筛选（红/橙/黄/绿/青/蓝/紫/粉/棕/灰/白/黑 13 档）
- 当前图纸用到的颜色自动置顶排序，手绘取色更快

### 4. 手绘编辑器

- 画笔 / 橡皮模式
- 色板横向滚动选择、当前色高亮
- 多步撤销 / 重做（最多 40 步）、清空画布、清除本地存档
- 桌面端支持 Ctrl+Z / Ctrl+Y 快捷键撤销重做
- 自动保存图纸到 localStorage（防丢失）、刷新恢复
- 刷新恢复存档时 toast 提示"已恢复上次未完成的图纸"
- 示例图纸一键载入（新用户无需上传即可体验完整流程）
- 项目库：多图纸存档，支持保存 / 载入 / 重命名 / 删除（操作带 toast 反馈）
- 滑块拖动只即时更新数字，松手后防抖重算（避免连续全量处理卡顿）

### 5. 统计与导出

- 色号用量统计（总颗粒数 + 分色号清单）
- 成品尺寸提示（按 5mm 豆径估算，如"8.0 × 8.0 cm"）
- 一键复制色号清单文本（可粘贴到微信群 / 笔记分享）
- 下载带色号图纸 PNG、无码图纸 PNG
- CSV 清单先预览后下载（预览弹窗含下载 / 复制按钮），下载时才扣额度
- 每次导出前确认"将消耗 1 次下载额度（剩余 N 次）"
- 打印图纸
- 移动端下载兼容（表单提交 / 浏览器下载兜底）

### 6. 学习与引导

- 拼豆品牌与尺寸指南（Perler / Hama / Artkal / Nabbi / Yant 的豆径、色号示例、特点）
- AI 优化快捷风格模板（Q版可爱、复古像素、透明贴纸、水墨国风、扁平卡通）

### 6. 卡密与授权

- 授权状态展示（AI 剩余 / 下载剩余）
- 卡密兑换弹窗、退出授权
- 未解锁时预览加水印（"未付款预览"）
- 受保护动作排队：兑换成功后自动继续执行
- 次数预警：AI / 下载剩余 1 次时提示"即将用完"
- 卡密可绑定最多 3 张不同图片（原为绑定单图即作废）

## 二、小程序端（`D:\pixelbeans-wechat`）

功能与 Web 端基本对齐，差异点：

- `wx.chooseMedia` 选图（相册 / 拍照），12MB 限制
- Canvas 2D 渲染（dpr 适配）
- 预处理面板（switch 开关 + 提示词）、AI 提示引导动画
- 色板选择器（picker）、向右滑动提示、免费 AI 体验（设备 ID 存储）
- 导出走两段式下载（`/api/download-prepare` + `wx.downloadFile`），避免大体积 base64 超限
- 本地存档 `wx.setStorageSync`、恢复与清除
- 弹窗打开时隐藏原生 canvas、关闭后重绘（避免被原生层遮挡）
- 后端地址通过 `config.js` 配置（开发者工具 127.0.0.1，真机改局域网 IP）
- 多步撤销 / 重做、示例图纸、项目库（多存档）、色名展示、复制色号清单
- AI 提示词快捷风格模板

## 三、卡密后端（9090 端口，`card-backend/`）

### 1. 卡密体系

- 卡密兑换（`/api/redeem-card`）：HMAC 签名会话令牌、HttpOnly Cookie（30 天）
- 授权状态查询（`/api/access-status`）
- 退出授权（`/api/logout-access`）
- 每张卡密 3 次 AI + 3 次下载，图片指纹绑定（首次使用绑定，换图拒绝 409）
- 次数用满自动作废；卡密失效 / 换图冲突统一返回"请使用新卡密"
- 免费 AI 体验：按设备 ID 一次，记录到 freeTrials

### 2. AI 优化（`/api/ai-optimize`）

- 对接火山引擎即梦（jimeng_t2i_v40）异步任务：提交 → 轮询 → 返回结果图（转 base64 data URL）
- 单任务并发限制（429 防并发）
- 成功 / 失败 / 超时（60 次 × 3 秒轮询）处理

### 3. 下载（`/api/download`）

- 校验卡密 + 图片绑定 + 次数后，透传 PNG（dataUrl）或 CSV（text），扣减下载次数
- 文件名清洗防路径注入、UTF-8 CSV BOM 处理

### 4. 其他

- CORS（跨域白名单）、IP 脱敏日志（保留最后一段为 0）
- 静态文件服务（主站 + 管理台）
- 数据持久化 `cards.json`（卡密 + 日志 + 免费试用），最多保留 1000 条日志
- 环境变量校验（生产模式拒绝弱密钥启动）

---

## 四、管理后台（`/卡密/index.html`）

- 管理员密钥验证（`x-admin-key` 请求头）
- 批量生成卡密（数量 1–200、前缀、备注）
- 卡密列表：状态、AI / 下载次数、绑定图片、备注、创建 / 使用时间
- 重置卡密（恢复 unused、清空次数与绑定）
- 统计卡片：未使用 / 已激活 / 已失效 / 已绑定图片数
- 最近 200 条操作日志（时间、类型、卡密、图片标识、详情、IP）
