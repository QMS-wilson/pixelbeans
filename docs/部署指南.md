# 生产部署指南

> 更新时间：2026-08-04

项目由两个 Node 服务组成：

| 服务 | 默认端口 | 说明 |
| --- | --- | --- |
| 前端静态服务（`server.js`） | 8789 | 主站页面 + 静态资源，`/api/*` 代理到后端 |
| 卡密后端（`card-backend/server.js`） | 9090 | 卡密、AI 优化、下载、管理台 API |

## 一、环境变量（生产必须配置）

在服务器上创建 `.dev.vars`（或直接注入环境变量），**必须**设置强随机值：

```ini
NODE_ENV=production
CARD_ADMIN_KEY=<强随机字符串，至少 32 位>
CARD_SESSION_SECRET=<强随机字符串，至少 32 位>
VOLC_ACCESS_KEY_ID=<火山引擎 AccessKey>
VOLC_SECRET_ACCESS_KEY=<火山引擎 SecretKey>
ALLOWED_ORIGINS=http://你的域名,https://你的域名
CLIENT_ORIGIN=https://你的域名
```

> 生产模式下密钥缺失或仍为默认值，后端会**拒绝启动**。
> 生成强随机密钥：`node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"`

## 二、Linux 部署（systemd + Nginx + HTTPS）

### 1. 上传代码并安装依赖

```bash
cd /opt/pixel-beads
npm install --omit=dev
cd card-backend && npm install --omit=dev && cd ..
```

### 2. 配置 systemd 守护前端

`/etc/systemd/system/pixel-beads-web.service`：

```ini
[Unit]
Description=Pixel Beads Web
After=network.target

[Service]
WorkingDirectory=/opt/pixel-beads
ExecStart=/usr/bin/node server.js
Restart=always
RestartSec=3
Environment=NODE_ENV=production
EnvironmentFile=/opt/pixel-beads/.dev.vars

[Install]
WantedBy=multi-user.target
```

### 3. 配置 systemd 守护后端

`/etc/systemd/system/pixel-beads-card.service`：

```ini
[Unit]
Description=Pixel Beads Card Backend
After=network.target

[Service]
WorkingDirectory=/opt/pixel-beads/card-backend
ExecStart=/usr/bin/node server.js
Restart=always
RestartSec=3
Environment=NODE_ENV=production
EnvironmentFile=/opt/pixel-beads/.dev.vars

[Install]
WantedBy=multi-user.target
```

启用并启动：

```bash
systemctl daemon-reload
systemctl enable --now pixel-beads-web pixel-beads-card
systemctl status pixel-beads-web pixel-beads-card
```

### 4. Nginx 反向代理 + HTTPS（Let's Encrypt）

`/etc/nginx/sites-available/pixel-beads`：

```nginx
server {
    listen 80;
    server_name 你的域名;

    location / {
        proxy_pass http://127.0.0.1:8789;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_read_timeout 180s;
    }
}
```

```bash
ln -s /etc/nginx/sites-available/pixel-beads /etc/nginx/sites-enabled/
certbot --nginx -d 你的域名
```

> 启用 HTTPS 后，`.dev.vars` 中设置 `COOKIE_SECURE=true`，Cookie 使用 `SameSite=None + Secure`。
> **9090 端口不要暴露公网**：管理台只通过 8789（Nginx 代理）访问；用防火墙限制 9090 仅本机。

## 三、Windows 部署（NSSM 守护）

如果部署在 Windows 服务器上，用 NSSM 把两个服务注册为 Windows 服务：

```powershell
nssm install PixelBeadsWeb "C:\Program Files\nodejs\node.exe" "C:\path\to\server.js"
nssm set PixelBeadsWeb AppDirectory "C:\path\to\project"
nssm set PixelBeadsWeb AppEnvironmentExtra NODE_ENV=production
nssm set PixelBeadsWeb Start SERVICE_AUTO_START
nssm start PixelBeadsWeb

nssm install PixelBeadsCard "C:\Program Files\nodejs\node.exe" "C:\path\to\card-backend\server.js"
nssm set PixelBeadsCard AppDirectory "C:\path\to\card-backend"
nssm set PixelBeadsCard Start SERVICE_AUTO_START
nssm start PixelBeadsCard
```

Windows 防火墙放行 8789（或由 Nginx 反代），**不建议放行 9090 到公网**：

```powershell
netsh advfirewall firewall add rule name="PixelBeads 8789" dir=in action=allow protocol=TCP localport=8789
```

## 四、数据备份

- 卡密数据唯一来源：`card-backend/卡密/cards.json`
- 后端已内置自动备份：每 6 小时最多一次，保留最近 30 份到 `card-backend/卡密/backup/`
- 建议另外定期把 `cards.json` 和 `backup/` 复制到异地存储（云盘 / 对象存储）
- 备份文件已禁止通过 HTTP 访问（静态服务拦截 `cards-backup-*.json`）

## 五、上线检查清单

- [ ] `CARD_ADMIN_KEY` / `CARD_SESSION_SECRET` 为强随机值
- [ ] 火山引擎密钥已配置且权限开通
- [ ] 9090 端口未对公网开放（或已加 IP 白名单）
- [ ] HTTPS 已启用，`COOKIE_SECURE=true`
- [ ] 两个服务已注册开机自启
- [ ] `npm test` 语法与冒烟测试通过
- [ ] `cards.json` 已做异地备份
